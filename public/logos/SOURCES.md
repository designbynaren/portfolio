# SVG logo sources

These assets are bundled locally and have no external runtime dependencies.
Brand names and marks belong to their respective owners; their use identifies tools and contact services.

- Figma, Illustrator, Photoshop, Premiere Pro, After Effects, Blender, LinkedIn, Gmail and WhatsApp: SVG Logos by Gil Barbara, CC0-1.0; exported from @iconify-json/logos 1.2.15. https://github.com/gilbarbara/logos
- Maya: Simple Icons, CC0-1.0; exported from @iconify-json/simple-icons 1.2.99. https://github.com/simple-icons/simple-icons
- ChatGPT/OpenAI and Claude: Lobe Icons, MIT; copied from @lobehub/icons-static-svg 1.95.1. https://github.com/lobehub/lobe-icons
- Higgsfield: Dashboard Icons collection (Apache-2.0). https://github.com/homarr-labs/dashboard-icons/blob/main/svg/higgsfield.svg

- Audition: original Adobe SVG, https://www.adobe.com/cc-shared/assets/img/product-icons/svg/audition.svg

SVG geometry is retained as supplied.

- DaVinci Resolve: full-colour vector by Asav / Blackmagic Design, public-domain simple brand geometry, via Wikimedia Commons: https://commons.wikimedia.org/wiki/File:DaVinci_Resolve_17_logo.svg. Original SVG: https://upload.wikimedia.org/wikipedia/commons/9/90/DaVinci_Resolve_17_logo.svg.
- Call: original generic SVG phone icon styled to match the coloured contact tiles.

- YouTube channel button: YouTube icon from the bundled @iconify-json/logos package (GilBarbara logos, CC0), served locally as youtube.svg.
